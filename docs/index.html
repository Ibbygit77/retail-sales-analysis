How this analysis was built

From raw data to dashboard, and the database design behind it

FormulasRevenue = quantity × unit price × (1 − discount)
Profit = revenue − quantity × unit cost
Margin = profit ÷ revenue
ToolsSQLite (joins, views, window functions), Python (data preparation and export), HTML, CSS and JavaScript (charts drawn as SVG, no chart library)
DataSynthetic data for a fictional retailer, generated with a fixed seed so every result can be reproduced. 20,612 order lines, 40 products, 12 stores.
